# Archived design briefs

Phase briefs whose work is fully implemented and verified. They are kept as design
history — the rationale and rejected alternatives are still authoritative — but they
are no longer maintained; the living documentation (`../AUTHORING_BUNDLES.md`,
`../PLAN.md`, root `CLAUDE.md`) supersedes them where they overlap.

A brief moves here only when its phase is 100% complete, including verification.

`PLAN_phases_1-13.md` is the frozen task-by-task history of the implementation plan
through 2026-07-14; `PLAN_2026-07-16_to_2026-08-08.md` continues it through
2026-08-08, when the [docs/changes/](../changes/README.md) convention was adopted and
`../PLAN.md` was cut back to a status summary plus an index of what's currently open.
Together they carry everything the living `../PLAN.md` no longer does.

`changes/` (once anything lands there) holds completed `docs/changes/<slug>/` folders,
moved here verbatim on resolution per `../changes/README.md`'s lifecycle — the same
"freeze it, don't delete it" rule as everything else on this page.

`spec/` holds narrative trimmed out of `../spec/` (measurements, incident write-ups,
"was X until Y" comparisons) each time a requirement is edited back down to
present-tense — see `spec/README.md`.
